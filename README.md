## Overview

![screenshot](https://media.discordapp.net/attachments/1464634656463786118/1568271480356081740/Captura_de_tela_de_2026-11-06_11-30-45.png?ex=6aef3621&is=6aede4a1&hm=9f65341341f065c1fd76dffa1e91ecef6f1e5a73a3d407a824fee12d317f5525&=&format=webp&quality=lossless)

This project consists of a responsive Bento Box layout designed to present essential features of a data management platform.

The layout uses different card sizes and arrangements to create a visually organized interface that adapts to different screen sizes.

### What I learned

During this project, I improved my understanding of responsive layouts using CSS Grid and Flexbox.

Some of the main concepts I practiced:

- **CSS Grid:** Creating different card arrangements using `grid-template-columns`, `grid-column` and `grid-row`.
- **Grid auto-flow:** Understanding how `grid-auto-flow` controls the automatic placement of grid items.
- **Flexbox:** Changing the direction and alignment of card content using `flex-direction` and `align-items`.
- **Media Queries:** Adapting the layout to different screen sizes using breakpoints at 1024px and 1280px.
- **Responsive sizing:** Using `clamp()` to create flexible spacing and padding values.
- **Image responsiveness:** Using `width: 100%`, `height: auto` and the `<picture>` element to control image dimensions.

One of the main challenges was organizing the cards into different grid structures while maintaining the desired layout at each breakpoint.

- Responsive Bento Box layout.
- Five feature cards with different layouts and sizes.
- Responsive card arrangements for mobile, tablet and desktop screens.
- Combination of CSS Grid and Flexbox.
- Flexible spacing using the CSS `clamp()` function.
- Custom typography using the Be Vietnam Pro font.
